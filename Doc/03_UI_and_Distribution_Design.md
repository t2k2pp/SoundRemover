# SoundRemover GUI画面設計・マルチ環境配布設計書

## 1. デスクトップGUI画面設計 (`PySide6` + `PyQtGraph`)

吹奏楽部の保護者の方が直感的に使え、かつ音声編集ソフト（DAW）のような正確な波形確認・範囲指定ができるモダンなダークテーマUIを採用する。

### 1.2 主要UIコンポーネントの役割

1. **上部クイックアクションバー**
   - **「動画/音声を開く」ボタン**: 動画（MP4/MOV/MTS等）または音声ファイルを読み込み、波形を高速描画する。
   - **「⚡完全ロスレス抽出（再エンコードなし）」ボタン**: 音声加工を行わず、動画内の元音声ストリームを100%無劣化のまま即座に別ファイルとして抜き出すワンクリック機能。
   - **ワンクリック・プリセット選択**:
     - `屋外ステージ録音（風切り音カット＋声除去＋音量最適化）`
     - `屋内ホール・体育館録音（空調ホワイトノイズ除去＋こもり解消EQ＋音量最適化）`
     - `話し声ピンポイント除去のみ（楽器音100%維持）`
     - `ホワイトノイズ除去のみ`
   - **演算デバイス選択コンボボックス**:
     - 起動時に利用可能なハードウェアを自動検出し一覧表示する（例：`自動 (CUDA: NVIDIA GeForce RTX 3060 Laptop GPU)`、`DirectML (AMD Radeon)`、`MPS (Apple Silicon)`、`CPU`）。ユーザーがいつでも手動切り替え可能。

2. **インタラクティブ波形＆リージョン選択ビューア (`WaveformWidget`)**
   - `PyQtGraph` を用い、数十分の演奏動画でも60fpsで軽快に拡大・縮小（マウスホイール）・スクロールが可能。
   - **初期状態は「範囲未選択」**とし、勝手に冒頭が選択されない設計とする。
   - **直感的な3通りの範囲選択・変更方法**:
     1. **波形上のマウス左ドラッグ**: 波形の任意の場所を左ドラッグするだけで新規に選択範囲を作成・変更でき、選択枠の左右端のドラッグで微調整が可能（右ドラッグまたはホイールで画面スクロール・ズーム）。
     2. **再生連動 `[In (開始点)]` / `[Out (終了点)]` ボタン**: 音声を再生しながら、現在の再生ヘッド位置をワンクリックで選択範囲の開始点または終了点にセット可能。
     3. **開始・終了秒数の数値スピンボックス＆「✖ 選択解除」ボタン**: 0.05秒単位での正確な数値微調整およびいつでも選択解除が可能。
   - 選択した範囲に対して以下の3つのアクションをワンクリックで実行可能：
     1. **「この区間だけ声/ノイズ除去を適用する」リストへの追加**（複数の時間帯を登録可能！）
     2. **「この区間をホワイトノイズ見本（演奏前のサーッという音）として登録」**
     3. **「この区間を1つの曲（チャプター）として分割書き出しリストに追加」**

3. **Original / Processed ワンクリックA/B聴き比べプレイヤー (`PlayerWidget`)**
   - 再生中に **「元の音声 (Original)」** と **「加工後 (Processed)」** のボタン（またはショートカットキー）をクリックすると、**再生位置（秒数）を一切途切れさせずにその場で元音声と加工後音声を切り替え**て聴き比べができる。
   - これにより、「楽器の音が痩せていないか？」「本当に声やノイズだけが消えているか？」を耳で確実に確認できる。

## 2. マルチ環境・ハードウェアアクセラレータ設計 (`device_manager.py`)

ユーザーの所有環境および他の保護者への配布環境すべてに対応する。

| OS / 環境 | 想定ハードウェア | 優先バックエンド | 備考 |
| :--- | :--- | :--- | :--- |
| **Windows 10/11** | NVIDIA GeForce / RTX (例: RTX 3060) | `cuda` (PyTorch CUDA) | 最高速でDemucs推論を実行 |
| **Windows 10/11** | AMD Radeon 内蔵/単体GPU・Intel Arc/Iris | `dml` (`torch-directml`) または `cpu` | CUDA非搭載Windows機でもGPU/高速CPU活用 |
| **macOS** | Apple Silicon (M1 / M2 / M3 / M4 Mac mini等) | `mps` (Metal Performance Shaders) | M4チップ等の内蔵GPUで高速推論 |
| **Linux** | AMD Ryzen AI Max+ 395 (Strix Halo) / Radeon | `cuda` (ROCm PyTorchは`torch.cuda`互換API) | ROCm経由で大容量統合メモリGPUをフル活用 |
| **全OS共通** | GPUなし / 互換性優先モード | `cpu` (マルチスレッド最適化) | どのPCでも確実に動作するセーフティネット |

### フォールバック安全設計
- 万が一、特定のGPUドライバやDirectML/MPS環境でDemucsの特定オペレータ（複素スペクトログラムSTFT等）が非対応エラーを出した場合でも、**アプリをクラッシュさせず、自動的に該当演算または全体をCPUへシームレスにフォールバックして処理を完遂する**自己修復機構を `vocal_remover.py` に組み込む。

## 3. 他の保護者への配布・セットアップ設計

- **FFmpegの自動解決 (`ffmpeg_manager.py`)**:
  - 一般の保護者のPCには `ffmpeg` がインストールされていないことが多い。
  - そこで `static-ffmpeg` / `imageio-ffmpeg` パッケージを依存関係に組み込み、OSのPATHに `ffmpeg` が無くても**アプリが内包するFFmpegバイナリを自動的に見つけて使用する**設計とする。
- **ワンクリック起動スクリプト**:
  - `run_windows.bat`（Windows用）および `run_unix.sh`（Mac/Linux用）を用意し、ダブルクリックまたは1コマンドで仮想環境・パッケージ確認からGUI起動まで完結する仕組みを提供する。
