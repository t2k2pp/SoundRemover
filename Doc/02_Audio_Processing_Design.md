# SoundRemover 音声処理・AIエンジン詳細設計書

## 1. ロスレス音声抽出・入出力エンジン (`extractor.py`)

### 1.1 対応入力フォーマット
- **動画ファイル**: `.mp4`, `.mov`, `.mkv`, `.avi`, `.mts`, `.m2ts`, `.webm`（スマートフォン、ビデオカメラ、一眼レフ・ミラーレスカメラの撮影データ全般）
- **音声ファイル**: `.wav`, `.flac`, `.m4a`, `.aac`, `.mp3`, `.ogg`

### 1.2 抽出モード
1. **完全ストリームコピー抽出（Direct Stream Copy / Re-encode なし）**
   - `ffprobe` で動画内の音声コーデック（例: `aac`, `pcm_s16le`, `pcm_s24le`, `flac`, `ac3` 等）を検査し、適切な拡張子（`.m4a`, `.wav`, `.flac`, `.ac3`）を自動選択して `ffmpeg -i <input> -vn -acodec copy <output>` を実行する。
   - 1ビットの再圧縮も行わないため、100%元の音声データが数秒で抽出される。
2. **ロスレス非圧縮PCM / FLAC 抽出**
   - 編集・保存用に、元のサンプリングレート（48kHzや44.1kHz）を維持したまま 24-bit PCM WAV (`pcm_s24le`) または 16-bit PCM WAV (`pcm_s16le`)、もしくは可逆圧縮 FLAC に変換して抽出する。

### 1.3 アプリ内部への読み込み仕様
- アプリ内で波形表示・音声加工を行う際は、FFmpeg経由で元のサンプリングレート（例: 48,000 Hz）・ステレオ2chを維持したまま `float32` 配列 (`shape: [channels, samples]`, 値域 `[-1.0, 1.0]`) としてメモリに展開する。

## 2. AIピンポイント声除去エンジン (`vocal_remover.py`)

### 2.1 アルゴリズム選定理由
屋外ステージや体育館、ホールでの録音では、以下のような「人の声」が混入する：
- 撮影している保護者や周囲の観客の会話・呼びかけ
- 曲間のMCやアナウンス、子どもの声
- 咳払い・くしゃみ

これらは管楽器（フルート、クラリネット、サックス、トランペット、ホルン等）の基音・倍音と同じ周波数帯（200Hz〜8kHz）に存在するため、周波数フィルタでは除去できない。
そこで、Meta Research が開発した **Hybrid Transformer Demucs (`htdemucs`)** を採用する。Demucs は時間領域（Waveform）と周波数領域（Spectrogram）の両方を Cross-Domain Transformer で解析し、`vocals`, `drums`, `bass`, `other` の4ステムに分離する。

### 2.2 吹奏楽向けの声除去合成ロジック
入力音声 $X(t)$ に対し、Demucs が推論したボーカル（人の声）成分を $V(t)$ とすると、楽器成分 $I(t)$ は単純な3ステム合算ではなく、**位相・量子化誤差を最小化する残差引き算方式**を基本とする：

$$Y_{\text{vocal\_removed}}(t) = X(t) - \alpha \cdot V(t)$$

- ここで $\alpha \in [0.0, 1.0]$ は **「声の除去強度（Vocal Reduction Ratio）」** である。
- **残差方式 ($X(t) - \alpha V(t)$) のメリット**:
  - `drums + bass + other` を足し合わせるよりも、元の音声 $X(t)$ から AI が検出した声成分 $V(t)$ だけを引き算する方が、**元の楽器の超高域空気感や微細な残響が100%そのまま残る**。
  - $\alpha = 1.0$（100%除去）で声を完全除去、$\alpha = 0.7$（70%除去）で「万が一管楽器のソロが声と誤認された場合でも楽器の音色変化を防ぎつつ、話し声を目立たなくする」といった微調整が可能になる。
- さらにオプションとして「人の声の周波数帯域（120Hz〜6000Hz）の成分のみを $V(t)$ から引き算する」**帯域制限付き声除去（Band-limited Vocal Subtraction）**を搭載する。これにより、シンバルの超高音やチューバ・大太鼓の重低音（120Hz以下、6kHz以上）はAIを通さず100%完全無劣化で保持される。

### 2.3 ピンポイント時間帯（リージョン）適用とクロスフェード
曲全体ではなく、ユーザーが波形上で選択した複数の区間 $\{[t_{\text{start}, k}, t_{\text{end}, k}]\}$ のみに声除去を適用できる。
- 各区間の前後にはマージン（例: 前後 0.5秒）を持たせて Demucs に入力し、推論端部の境界アーティファクトを回避する。
- 元の音声 $X(t)$ と処理済み音声 $Y(t)$ の切り替え境界には、長さ $T_{\text{fade}}$（デフォルト 50ms）の **Raised-Cosine（ハン窓）イコールパワー/リニアクロスフェード** を適用し、繋ぎ目の「プツッ」というクリックノイズを完全にゼロにする。

## 3. ホワイトノイズ除去＆屋外環境フィルタ (`noise_reducer.py`, `eq_filter.py`)

### 3.1 スペクトルゲーティングによるホワイトノイズ・定常ノイズ除去 (`noise_reducer.py`)
カメラのマイクプリアンプが発する「サーッ」というホワイトノイズや、ホール・体育館の空調音（エアコン・換気扇の「ゴーッ」「ブーン」という定常音）を除去する。
- **モードA：自動推定（Stationary / Non-stationary Spectral Gating）**
  - 音声全体から定常的な背景ノイズフロアを統計的に推定して除去する。
- **モードB：ノイズプロファイル学習（Noise Sample Learning）【推奨】**
  - ユーザーが波形上の「演奏が始まる前の無音（環境ノイズのみ）の1〜3秒間」を **「ノイズ見本（Noise Profile）」** として指定する。
  - その区間の周波数ごとの平均振幅・分散を学習し、そのノイズ成分のみをスペクトル領域で引き算する。
- **楽器保護パラメータ**:
  - `prop_decrease`（ノイズ減衰率: デフォルト 0.75〜0.85）：1.0（100%）にしすぎるとフルートやシンバルの余韻が「ミュージカルノイズ（水中にいるような音）」になるため、自然な減衰率と平滑化（周波数・時間スムージング）を設定可能にする。

### 3.2 屋外風切り音対策（スマート風切り音サプレッサー）・ハイパスフィルタ＆吹奏楽イコライザー (`eq_filter.py`)
ゼロ位相歪み（`scipy.signal.sosfiltfilt` による双方向フィルタリング）を採用し、楽器間の位相ズレを起こさずに周波数補正を行う。
1. **風切り音・空調振動除去ローカット（High-Pass Filter）**
   - 屋外の風がマイクに当たった際の超低周波ノイズや、ステージの足音振動を除去する。
   - カットオフ周波数：デフォルト `45 Hz`（25Hz〜150Hzで調整可能）。
2. **スマート風切り音除去（Mid/Side 乱流カット＋動的吹かれサプレッサー）**
   - スマートフォン等のステレオマイク録音において、ステージから届く楽器の低音（30〜300Hz：チューバ、ベース、バスドラム等）は波長が長いため左右のマイクに同相（Mid成分 $M = \frac{L+R}{2}$、L/R相関 $+0.90\sim+0.99$）で届く。一方、マイクに直接当たる風切り音（吹かれ）は左右のマイク穴に独立した空気の渦として当たるため、逆相・非相関成分（Side成分 $S = \frac{L-R}{2}$、L/R相関 $\approx 0$）が支配的となる。
   - **第1段階（低域Side乱流カット）**: 280Hz以下のSide成分 $S_{\text{low}}(t)$ をゼロ位相ハイパスフィルタで減衰させ、楽器の低音（Mid成分）を一切削らずに左右非相関な風乱流ノイズを除去する。
   - **第2段階（風センサー連動・動的Mid吹かれ抑制）**: 30〜260Hz帯域における瞬間的な乱流指標 $R_{\text{wind}}(t) = \frac{\text{Env}(|S_{\text{low}}(t)|)}{\text{Env}(|M_{\text{low}}(t)|) + \epsilon}$ を算出し、風が吹いて $R_{\text{wind}}(t)$ が閾値を超えた瞬間のみ、Mid成分の低域（30〜240Hz）を動的に減衰させる。風が吹いていない区間では減衰量を $0\text{ dB}$ とすることで、ベースやチューバの豊かな低音を100%維持する。
3. **吹奏楽向け4バンド・トーンイコライザー（EQ）**
   - **Low / Warmth (80Hz, Low-Shelf)**: 屋外ステージで抜けてしまいやすい低音楽器（チューバ、ユーフォニアム、ティンパニ）の厚みを補強（-12dB 〜 +12dB）。
   - **Low-Mid / Mud Cut (280Hz, Peaking, Q=1.2)**: 体育館や反響過多なホールで「モコモコ」とこもる中低域をスッキリ整理（-12dB 〜 +12dB）。
   - **High-Mid / Presence (2.5kHz, Peaking, Q=1.0)**: 木管・金管のメロディラインの明瞭度や、逆に耳に痛い帯域の調整（-12dB 〜 +12dB）。
   - **High / Brilliance & Air (8.0kHz, High-Shelf)**: 金管の華やかな倍音やトライアングル・シンバルのきらびやかさ・空気感を調整（-12dB 〜 +12dB）。

## 4. 吹奏楽向けマスタリング・曲分割・書き出しエンジン (`mastering.py`)

### 4.1 なぜ吹奏楽には特別な音量調整が必要か
吹奏楽はポップスと異なり、ダイナミックレンジ（最小音量 $pp$ と最大音量 $ff$ の差）が極めて広い。スマホやビデオカメラで録音すると「最大の打楽器・金管の音量に合わせて録音されるため、普段の音量が非常に小さく聴こえる」という課題がある。

### 4.2 ラウドネスノーマライズ＆トゥルーピーク・リミッター
1. **ITU-R BS.1770-4 ラウドネス正規化 (`pyloudnorm`)**
   - 聴感上の音量（Integrated Loudness: LUFS）を計測し、目標値（例: `-16.0 LUFS`（吹奏楽・クラシック推奨の広いダイナミクス維持）〜 `-14.0 LUFS`（YouTube・スマホ再生向けの聴きやすい音量））に自動調整する。
2. **音割れ防止ソフトニー・ピークリミッター（Soft-Knee Lookahead Limiter）**
   - 音量を上げた結果、フォルティッシモ（$ff$）やシンバル・バスドラムの瞬間的なピークが `0 dBFS` を超えてデジタル音割れ（クリッピング）するのを防ぐため、設定上限（Ceiling: デフォルト `-1.0 dBFS`）を超えるピークのみを滑らかな包絡線で抑え込む。

### 4.3 曲ごとの分割（チャプター切り出し）とフェードイン・フェードアウト
- 1本の長い発表動画（例：30分の定期演奏会ステージ）から、複数の曲区間をリスト登録できる。
- 各曲の書き出し時に、冒頭のフェードイン（例: `0.5秒`）と末尾の拍手終わりのフェードアウト（例: `2.0秒`、コサインカーブ）を自動適用して個別ファイルとして一括出力できる。

## 5. 音響・周波数特性＆ノイズ自動診断エンジン (`analyzer.py`)

ユーザーが読み込んだ動画・音声ファイルの音響特性を数値・視覚的に把握し、最適なフィルタ設定を自動提案するための診断エンジン。

### 5.1 診断項目
1. **5帯域スペクトルエネルギー＆ステレオ相関解析**
   - `Sub-Bass (20-60Hz)`: 超低域振動・強い風吹かれの有無（RMS dB, L/R相関）
   - `Wind / Bass (60-180Hz)`: チューバ・ベース基音および風切り音主要帯域（RMS dB, L/R相関）
   - `Low-Mid (180-400Hz)`: ホール・体育館の反響・こもり帯域（RMS dB, L/R相関）
   - `Mid (400-2500Hz)`: 木管・金管の主旋律および人の声の帯域（RMS dB, L/R相関）
   - `High (2500-10000Hz)`: 倍音・シンバル・空気感およびホワイトノイズ帯域（RMS dB, L/R相関）
2. **風切り音（マイク吹かれ）発生区間の自動スキャン**
   - 0.5秒ステップで `30-300Hz` の Mid/Side 比率（`|Side| / |Mid|`）と低域レベルを検査し、風切り音が発生している時間帯リスト `[start_sec, end_sec]`（連続区間は自動マージ）と深刻度（なし／軽度／中度／重度）を出力する。
3. **ホワイトノイズ見本（静寂区間）の自動検出**
   - 音声全体から最もエネルギーが低く定常的な区間（0.5〜2.5秒間）を探索し、ホワイトノイズ学習用の推奨見本区間として提案する。
4. **推奨パラメータの自動算出 (`recommended_config`)**
   - 風切り音の深刻度に応じた `wind_reduction_enabled` / `wind_reduction_strength` および `highpass_cutoff_hz` の自動設定。
   - 中低域（180-400Hz）と中高域（400-2500Hz）のエネルギー比に基づく「こもり解消EQ（Low-Mid 280Hz）」や「低音補強（Low 80Hz）」の推奨値算出。
