# SoundRemover 🎺🎬

**中学生・高校生の吹奏楽部や音楽発表会の撮影動画から、ロスレス（無劣化）で音声を抽出し、屋外ステージの雑音や観客の話し声・ホワイトノイズをピンポイントで除去して高音質な音楽ファイルを作成するデスクトップアプリ**です。

---

## 主な特徴

1. **完全ロスレス（無劣化）音声抽出**
   - 動画内の音声ストリームを再エンコードなしでそのまま抜き出す「完全ストリームコピー抽出（`ffmpeg -vn -acodec copy`）」と、24-bit 非圧縮 WAV / 可逆圧縮 FLAC 出力に対応。
   - アプリ内部に FFmpeg バイナリを自動解決する仕組み（`static-ffmpeg` / `imageio-ffmpeg`）を備えており、FFmpeg を別途インストールしていない他の保護者のPCでもそのまま動作します。

2. **AI音源分離（Hybrid Transformer Demucs）による「人の声」ピンポイント除去**
   - 従来のイコライザーでは消せなかった「演奏と重なった観客の話し声・呼びかけ・アナウンス・咳払い」を、AI音源分離モデル（`htdemucs`）を用いて**人の声（Vocals）成分だけ引き算**することで除去します。
   - **楽器保護帯域制限モード**により、チューバやバスドラムの重低音（110Hz以下）およびシンバルや金管の超高域倍音（6.5kHz以上）はAIを通さず100%元の波形を維持します。

3. **必要な数秒間だけ適用する「ピンポイント範囲（リージョン）指定」**
   - 曲全体にかけるだけでなく、波形を見ながら「01:12〜01:18 の観客の話し声だけ消す」といった**複数区間のピンポイント指定**が可能。境界は自動で滑らかにクロスフェードされ、それ以外の演奏部分は100%無加工・無劣化で維持されます。

4. **ホワイトノイズ除去（ノイズ見本学習対応）＆屋外ステージ用フィルタ・EQ**
   - 演奏開始前の「サーッ」「ゴーッ」という空調音・ホワイトノイズ区間を波形上で選択して学習させ、ピンポイントにホワイトノイズだけを除去するスペクトルゲーティング機能。
   - 屋外の風切り音（吹かれ）を抑えるローカットフィルタと、吹奏楽向けの4バンドイコライザー（低音補強・ホールのこもり軽減・木管金管の明瞭度・倍音空気感）を搭載。

5. **吹奏楽向けマスタリング（ラウドネスノーマライズ＆音割れ防止リミッター）と曲分割出力**
   - ピアニッシモ（極小音）からフォルティッシモ（大音量）まで音量差が大きい吹奏楽録音に対し、音割れ（クリッピング）を確実に防ぎながら聴きやすい音量（LUFS）へ自動調整します。
   - 1本の長い撮影動画から「1曲目」「2曲目」「アンコール」のように複数曲をリスト登録し、フェードイン・フェードアウト付きで一括分割書き出しが可能です。

6. **Original / Processed ワンクリックA/B聴き比べプレイヤー**
   - 再生位置を途切れさせずに「元の音声」と「加工後の音声」をワンクリックで切り替え、楽器の音色が痩せていないか耳で確認できます。

7. **マルチ環境・マルチGPU自動対応**
   - **Windows**: NVIDIA GPU (`CUDA`) / AMD・Intel GPU (`DirectML`) / マルチコア `CPU`
   - **macOS**: Apple Silicon M1/M2/M3/M4 (`MPS`) / `CPU`
   - **Linux**: AMD Strix Halo・Radeon (`ROCm`) / NVIDIA (`CUDA`) / `CPU`

---

## 起動方法

### Windows の場合
`run_windows.bat` をダブルクリックするか、ターミナルで以下を実行してください：
```powershell
uv run sound-remover
```

### Mac / Linux の場合
```bash
chmod +x run_unix.sh
./run_unix.sh
```
